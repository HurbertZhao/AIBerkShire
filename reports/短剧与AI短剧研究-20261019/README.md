# 短剧与AI短剧研究

信息截止：2026年10月19日。

[阅读完整报告](短剧与AI短剧深度研究报告-20261019.md)

报告涵盖国内与海外市场、免费和付费模式、AI制作案例与全成本、上市公司价值归属、实际影响及2026—2036年三种情景。40组来源集中列在报告末尾，事实、企业自报与预测分别标注。

核心判断：短剧需求与AI生产力改进已有证据，普通制作商持续超额盈利仍需验证。研究重点是用户、获客、内容权利与现金流，而非上线数量或概念热度。
